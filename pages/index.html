Platforms

작업하는 곳에서 바로

데스크톱 앱

Electron 기반. 영상 정합과 GitHub 릴리즈 업데이트 확인을 지원합니다.

  • 릴리즈 페이지에서 설치 파일 다운로드
  • 또는 소스에서 바로 실행
$ npm ci
$ npm run dev

VS Code 확장

의료 영상 파일을 클릭하면 편집기 안에서 열립니다. SSH·컨테이너 작업 공간에서는 필요한 단면만 전송하고 캐시합니다.

  • VS Code 1.85 이상
  • Extensions → … → Install from VSIX…
$ npm ci
$ npm ci --prefix vscode-extension
$ npm run package:vscode

웹 플랫폼

서버의 CT 볼륨을 브라우저에서. 계정, 가입 승인, 관리 페이지를 갖춘 다중 사용자 플랫폼입니다.

  • 내 컴퓨터 파일은 브라우저에서만 보기 또는 업로드
  • 외부 공개 시 HTTPS 필수
$ docker compose up -d --build
# http://<서버 IP>:8080
